comfyui 可以用的放大模型

omfyUI 的放大模型主要分两大类：经典 ESRGAN 系（走 UpscaleModelLoader + ImageUpscaleWithModel 节点，轻量、全显存通用）和 扩散 / AI 放大（走 SUPIR、Ultimate SD Upscale 等，质量更高、吃显存）。下面按你的用途和显存给你排个序。

一、经典 ESRGAN 放大模型（推荐优先）

放到 ComfyUI\models\upscale_models\ 目录即可，配合两个节点使用，4K 以下显存压力很小（3090 24G 随便跑）：

表格

模型 特点 适用
4x-UltraSharp 通用王者，人像 / 风景细节干净 写实照片首选
RealESRGAN_x4plus 通用、自然，不易过锐 通用照片
RealESRGAN_x4plus_anime_6B 动漫专用 6B 版 二次元 / 插画
4x-AnimeSharp 动漫线条、色块更锐利 动漫线稿
4x_NMKD-Siax_200k 细节强，适合复杂纹理 皮肤 / 布料细节
4x_foolhardy_Remacri 保真度高的真实感放大 写实放大
2x_Valar_v1 轻度放大更自然 轻微提升分辨率

下载源：HuggingFace（搜 Fictiverse/UltraSharp、Kim2091/AnimateSharp、camenduru/RealESRGAN）或 OpenModelDB。

二、AI / 扩散放大（质量天花板，吃显存）

表格

方案 显存需求 特点
SUPIR（SUPIR_model_fp16） fp16 版约 12G+ 起步，你的 3090 够用 目前放大质量最强，走 SUPIR_Upscale 节点；建议配合 ComfyUI-SUPIR 自定义节点
Ultimate SD Upscale 低显存也能跑（分块） 图块式 latent+img2img 放大，老牌稳定，可调降噪强度
ControlNet Tile + 放大工作流 显存中等 用 tile 控制细节保真，AI 细化效果好
Latent Upscale（内置 Upscale Latent） 极低 速度快但细节一般，适合粗放大

三、建议（结合 3090 / RTX PRO 6000）

  • 日常写实放大：4x-UltraSharp + ImageUpscaleWithModel，最省事、效果最稳。
  • 追求极限质量、显存充足：SUPIR fp16（3090 24G 可跑，PRO 6000 更轻松），尤其适合放大后再出图的工作流。
  • 动漫 / 插画：4x-AnimeSharp 或 RealESRGAN anime 6B。
  • 低显存或大批量：Ultimate SD Upscale 分块处理。
